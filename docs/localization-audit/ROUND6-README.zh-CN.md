# 第六轮任务中文覆盖测试版

本包必须安装到新的独立测试副本。第三轮稳定版、第四轮 BMD 测试版、第五轮任务测试版均保留。不要把本轮 JSON 单独复制给旧 Main.exe。

## 覆盖范围

本轮将当前已核对的 QuestWords 2,288 条记录全部加入中文覆盖（含之前 64 条），涵盖任务介绍、接受/拒绝回答、进行中提示、摘要和标题。旧转职标题共 7 条也已覆盖。沿用 28 条技能名称、20 条顶部提示，不改变技能属性、任务条件、目标、奖励、协议或服务器。

这是“每条记录都有中文文本”，不代表没有任何拉丁字母。未确认的专有名称、技术命令、快捷键继续保留，避免玩家找错任务目标。服务端发送的英文消息、动态插入的未翻译装备/怪物名称仍可能是英文。服务端未启用或角色不满足条件的任务不能算已实机验证。

新增 24 条任务界面资源，包括任务条件、奖励、等级、金币、物品、经验和活动进度。普通任务及委托任务窗口的经典/现代主题标题随语言切换。完整 ID 对照与待复核专名见 `round6-quests.tsv` 和 `round6-review.tsv`。

## 显示与回退

覆盖仅在 zh-CN 下、原始 ID 和原文同时匹配时生效。en 使用原始英文资源。不修改 BMD 二进制或其读取编码。原文件中 78 条非 UTF-8 记录通过原 Windows 加载器的实际解码结果核对；英文模式仍保留原版表现，不能承诺修复这些原文的既有乱码。

长任务正文保持原来的分页窗口。长摘要使用现有可滚动任务列表，中文不再受八行临时数组截断；标题和回答仍有较小长度上限。语言切换重建缓存，缺失 ID 或原文不匹配回退原文。无效覆盖文件会整体停用并记录日志。

部分原文自身存在目标或地点矛盾，例如 18096 的介绍写地狱猎犬怪而目标写地狱蜘蛛，19047 的介绍写金甲兽而目标写破坏骑士。这里忠实保留原文，未擅自改变任务目标。客户端提示与服务器实际目标有分歧时应单独核对。

## 安装与验收

1. 复制自己的合法完整第五轮客户端到新目录，退出新副本，将 ZIP 解压至根目录，使 Main.exe、Data、shaders 同层。
2. 保留自己的 config.ini、Noto Sans SC 字体和游戏素材。本包不含账号、密码、服务器地址或原始 BMD。
3. 用 test0 检查当前可接受的任务：标题、正文、选项、翻页、接受后提示、T 键摘要、交付和奖励。特别检查长摘要可向下滚动且没有文字丢失。
4. 打开任务后切换 zh-CN→en→zh-CN，并分别检查经典/现代主题及常用缩放下的方框、截断、重叠。
5. 检查登录、移动、战斗、拾取、NPC 商店、Helper 保存及启停、幻影导师气泡。气泡逻辑沿用第五轮，不再改动。

自动资源检查、字体字形表检查和 CTest 不等于上述实机操作通过。本包构建元数据中的游戏验证默认未测试，实际人工结果另行记录。

回退时退出第六轮，启动保留的第五轮或第三轮副本即可，不需修改 NAS、服务端或数据库。先退出旧角色再登录新客户端，避免同账号同时在线。
