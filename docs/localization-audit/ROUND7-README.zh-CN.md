# 第七轮常用名称中文测试版

以已通过用户验收的第六轮 1438c53 为基线。仅补充显示名称和技能中文覆盖，不改英文、BMD 二进制、属性、任务条件、协议、助手规则或服务器。第六轮以及更早客户端必须保留。

名称组可能对应多个怪物 ID；未命名的保留 NPC 记录仍计入缺失，不擅自命名。物品包括偃月刀、巨蛇魔剑、背叛者、天行者、真红之剑、帝王之剑、常用斧和槌、暴风／幻月五件防具，以及星云火链和火舞旋风卷轴。怪物包括幻术园的怪异的兔子、疯狂的兔子、污染之蝶、灰熊、残暴的灰熊，以及部分卡利玛怪物和冰之魔犬。NPC 包括塞尔维斯、幻术园商人、摩斯、家族管家和罗兰市场商人。

技能包括圣盾防御、地裂斩、牙突刺、升龙击、旋风斩、天地十字剑、召唤类技能、钻云枪、冰封箭、穿透箭、玄月斩、天雷闪、圣导师技能和召唤术师技能。每个译名及其稳定 ID、原文和术语依据分别见 `round7-item-names.tsv`、`round7-monster-names.tsv`、`round7-npc-names.tsv`、`round7-skill-names.tsv`。

本轮不扩大任务正文修改。第六轮的 2,288 条 QuestWords、7 条转职标题、20 条顶部提示和原有 28 条技能覆盖原样保留。任务正文中先前保留的英文专名（例如 Ashcrow、Silvia）仍可能出现；中文名称已加入 JSON 不代表这些独立正文自动替换。Game/Dialog 资源覆盖率不变。

## 助手自定义拾取

现有 `HelperPickupFilter.cpp` 使用当前显示名称进行区分大小写的子串匹配。本轮保留此规则及用户设置。中文模式中，英文 `Double Blade` 关键词需改为 `真红之剑`；`Ashcrow` 需改为 `暴风`。切到英文后，需要对应英文关键词。可保留两种语言的关键词，但请逐项实测；本包不会自动重写或清空列表。金币、宝石、套装、卓越分类选项按原规则执行。

## 安装、验收和回退

1. 退出将要安装的新副本。将自己的完整第六轮客户端复制为新的 `client-zh-CN-round7-names-test` 目录，再把本 ZIP 解压覆盖到新副本根目录，使 Main.exe、Data、shaders 同层。
2. 保留现有 config.ini、账号、服务器地址、端口、Noto Sans SC 字体及合法游戏素材。本包不包含 config.ini、密码或原始 BMD。不要只复制覆盖 JSON 给旧版 Main.exe。
3. 启动新副本，用 test0 检查背包、地面拾取提示、商店与目标名称。可在铁匠汉斯检查斧／槌，按实际持有装备检查武器附带技能；幻术园的商人和怪物需用有权限进入该地图的角色查看。
4. 检查 zh-CN→en→zh-CN 后背包／商店／技能提示与 NPC 名称刷新；未翻译 ID 应回退英文。按实际可用内容验收，不要求创建道具或修改角色数据。
5. 检查助手设置保存、启停及中英文自定义拾取关键词。回归登录、移动、战斗、拾取、NPC 商店、任务翻页和 T 键摘要；检查经典／现代主题、常用缩放下的方框、截断和重叠。
6. 回退时退出第七轮，启动原样保留的第六轮即可；不需要修改、重启 NAS 或服务端。避免同账号在多个窗口同时在线。

资源校验、字体字形表校验、编译与 CTest 和游戏内人工验收分别记录。构建时的人工状态均为未测试，不能沿用第六轮通过结论。

## 留待复核

未确认的专有名称继续保留英文，例如 Iris 系列、部分高级武器、活动 NPC 和大师技能。现有 `Scroll of Electric Spark`（12,24）译为“星云火链卷轴”，与本轮按 Fire Burst（61）核对的卷轴（12,21）出现译名冲突；本轮不擅自修改既有成果，此项需要单独核对对应技能关系。名称数据中 419／420／421 的 model 常量字面名与英文名称不同，也未据此重排 ID 或模型。服务端直接发送的英文不受这些客户端覆盖影响。
