## 译文依据和边界

Game 使用仓库已有繁体译文作为初稿，经简体转换和逐条修正，保留所有资源键、格式占位符、命令和控制符。物品/怪物按原 ID 和英文逐项映射；技能覆盖层同时检查 ID、原英文和原始 BMD 哈希。原始英文资源及 BMD 不变，未覆盖项回退英文。

装备专名参考国服资料及带 ID/国际服名的资料页。例如 Venom Mist 对应法魂玄灵、Thunder Hawk 对应奔雷、Grand Viper Staff 对应死神之杖；不按英文词面套用相近装备名。普通描述及大师技能后缀使用一致的中文术语，不能把这些译法都称为官方译名。无可靠版本对应的专名保留英文，详见 `round9-pending-*.json`。完整新增 ID、英文、译文见 `round9-*.tsv`，资料依据见 `ROUND9-SOURCES.md`。

服务端发送的登录、库存已满、NPC 尚未实现、重置未启用、左侧任务击杀进度等仍可能英文。客户端设置不会改变服务器选择的语言；本轮没有对收到的玩家聊天或任意消息做字符串替换。

## 安装和回退

1. 复制完整第八轮客户端为 `client-zh-CN-round9-full-test`，不要覆盖第八轮。
2. 退出新副本，将 `MuMain-v1.37.0-zh-CN-round9-full-test.zip` 解压覆盖到该副本根目录，Main.exe、Data、shaders 同层。
3. 保留原 config.ini、地址和端口、字体、合法游戏素材。更新包不包含个人配置、密码、原始 BMD 或未经授权素材。
4. 回退时退出第九轮，启动保留的第八轮即可。不要让同一账号在两个客户端同时在线。

## 人工验收

- 用 test0 登录；检查勇者大陆、冰风谷（冰封大陆）和仙踪林的商店、地面/背包装备与怪物名称。
- 查看角色已有主动技能和大师技能名称；没有对应技能或物品的项目标记未测，不更改角色数据。
- 检查装备职业、幸运、卓越、镶嵌、套装、合成、仓库、交易等常见说明，以及窗口宽度、换行、遮挡和方框。
- 检查 zh-CN→en→zh-CN 后物品、怪物、NPC、技能、任务、顶部提示、HUD 标签恢复正确；某些原有窗口需要重新打开才刷新静态文本，应记录具体窗口。
- 检查移动、战斗、拾取、商店、任务翻页、Helper 保存及启停。
- Helper 自定义拾取按当前显示名称做子串匹配。此前保留英文的物品现在变为中文时，请相应更新关键词；不会自动改写、清空你的设置。中英文切换后需分别核对关键词。
- 经典/现代主题与常用缩放分别检查。字体字形和缓冲区检查不能替代全部界面的视觉验收。
