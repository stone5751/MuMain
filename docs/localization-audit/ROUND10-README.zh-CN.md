# 第十轮装备与角色状态显示测试版

复制完整的第九轮客户端到新目录，将本包解压到新副本的 Main.exe 所在目录。沿用副本中的 config.ini。回退时退出第十轮，重新启动第九轮客户端。

本轮补齐 187 条物品条件名称和 194 条物品专属说明。角色状态图标和任务要求、奖励共用按状态 ID 取名的显示方法。158 个状态名称、134 段非空状态说明和 49 个套装前缀由客户端在简体中文模式按 ID 和原文匹配。装备名称跟随物品名称语言选项。英文模式使用原文。

实机请依次检查幻影导师祝福的状态提示、宝石组合数量、变身戒指的动态名称及古代套装前缀。切换英文再切回简体中文，核对同一件物品和状态图标。若当前任务包含状态条件或奖励，再核对任务中的状态名。左侧由 OpenMU 下发的击杀进度仍会保留服务端原文。角色没有遇到的物品与状态请记为未测。
