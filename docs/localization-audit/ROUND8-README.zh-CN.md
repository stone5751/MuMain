## 截图中仍可能出现的英文

“{0} entered the game.”、“Talking to this NPC ({0}, {1}) is not implemented yet.”、“Reset is not enabled.” 来自 OpenMU v0.10.1 的 PlayerMessage.resx，分别为 PlayerEnteredGameMessage、TalkingNotImplementedFormat、ResetNotEnabled。玩家名和服务端 NPC 名称参数不会因本包改变。客户端中文设置不会自动切换服务端语言。

左侧“[Dispose of the Town Plunderers! (Dark Lord)] Defeat Lich - 1/15”与客户端任务窗口覆盖是不同路径，服务端按任务配置名称及怪物名称组装进度通知；本包不会匹配替换收到的任意聊天文本。因此任务窗口已中文，左侧仍可能英文。独立服务端方案见 ROUND4-SERVER-PLAN.zh-CN.md；本轮未实施。

Leo 的头顶目标名称由客户端数据决定；若服务端对话包显式携带英文说话者名，气泡中的名字仍可能保持英文，需实机区分。背包中 Zen 的图像标签不在本次文本修改范围。不确定的高级装备、大师技能及其他专名继续保留英文。

## 安装与回退

1. 复制完整第七轮客户端为 `client-zh-CN-round8-equipment-test`。保留第七轮原目录和更新包。
2. 退出新的测试副本，将本 ZIP 解压覆盖到新副本根目录，使 Main.exe、Data 和 shaders 同层。包内包含新编译的 x64 Main.exe、必要 DLL、着色器、累计中文 JSON、任务 RML、构建及测试信息。
3. 保留自己的 config.ini、服务器地址/端口、账号、Noto Sans SC 字体及合法游戏素材。ZIP 不包含 config.ini、密码、原始 BMD 或游戏素材。
4. 回退时退出第八轮并启动原样保留的第七轮即可。不要让同一账号在多个客户端同时在线。
