# MuMain v1.37.0 简体中文 Windows x64 更新包

本包用于覆盖到已有的原版 v1.37.0 客户端**副本**。不含完整游戏素材，不含 config.ini，不修改 NAS 服务端、数据库或协议。
实际源码提交、构建编号和测试状态以包内 `localization-build.txt`、`ctest-results.xml` 为准；各文件 SHA-256 在 `files.sha256`。
第三轮增加270条常用界面/系统文本、60组物品名、22组怪物名和6组NPC名。原有翻译保留。技能、任务和滚动提示的BMD未改动，也未包含在本包中。
只有工作流成功编译、链接、通过原生 CTest 及打包验证后才生成本包。**这些自动化结果不代表游戏内人工测试通过。**

## 安装

1. 退出客户端。将现有 `D:\Downloads\MuMain` 中的客户端运行文件复制到独立目录，例如 `D:\Games\MuMain-zh-CN-test`，不要复制 `source-v1.37.0`、`localization-output`、`localization-backup` 等开发目录。
2. 保留原始目录作为回退副本。确认新目录原有 Main.exe、DLL、shaders、Data、fonts 和自己的 config.ini 都在。
3. 将本 ZIP 解压到新目录根部，覆盖 Main.exe、DLL、shaders 以及对应 Data/Items、Data/Monsters JSON。不要多套一层 ZIP 文件名目录。
4. config.ini 沿用原文件；保持 `[UI] Locale=zh-CN`、`Font=Noto Sans SC`。服务器地址与端口仍取原配置，勿替换成示例配置。
5. 从新目录运行 Main.exe。原运行目录和源码目录的 Main.exe 都不是这个更新包的验证目标。

## 回退

退出测试客户端，重新运行未覆盖的原目录即可。若已覆盖原目录，退出后从备份恢复 Main.exe、DLL、shaders、Data/Items、Data/Monsters；恢复测试期间改动过的客户端设置。不要从更新包寻找 config.ini，它有意不包含此文件。
