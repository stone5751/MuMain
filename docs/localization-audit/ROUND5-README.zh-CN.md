# 第五轮任务中文与 NPC 气泡测试版

本包仅安装到独立第五轮客户端副本，保留第三轮稳定版和第四轮测试版。沿用自己的合法游戏素材、英文 BMD、字体和 config.ini，不更改 NAS 服务端。

## 已确认任务

幻影导师的 15–25 级任务窗口显示“任务”“消灭城外的劫掠者！”及完整中文正文，分别对应既有 Game Quest 资源、QuestWords 18902、18011。旧版和现代主题均绑定当前语言，切换 en 后恢复英文。

NPC 正文使用独立的 quest-dialogue 覆盖类别，仍按原始 QuestWords ID 和英文原文匹配。正文最多 200 个 UTF-16 单位，仅用于原有 35 行分页正文入口；任务列表标题、回答和其他通用文本仍限制为 50。不会把长正文送入标题的小缓冲区。原始 BMD、任务条件、进度、奖励和回答 ID 不变。

覆盖文件只有第五轮及更新的对应客户端支持；不要把本轮 JSON 单独覆盖回第三、第四轮。未翻译项和其他语言回退英文，坏文件会停用整份覆盖并记录日志。

## 安装、测试与回退

自动 NPC 闲聊仅在同一 NPC 的同句仍可见时合并重复触发；气泡按原计时消失，之后可再次出现。不同内容继续按原方式显示。普通玩家聊天、服务器消息和任务回答不经过该去重入口。请站在幻影导师附近观察多次闲聊周期，并核对正常 NPC 交互仍可使用；自动测试通过不能替代此实机检查。

## 扩展范围与剩余英文

第五轮新增 49 条覆盖：46 条 QuestWords（正文/回答/摘要/标题）和 3 条旧转职标题。累计 117 条覆盖，其中 QuestWords 64 条、旧转职标题 5 条；其余技能和顶部提示沿用第四轮。任务正文页与 T 键任务列表的窗口标题在两种主题下均可随语言切换。

新增任务包括幻影导师的“猎杀蜘蛛！”（1–14 级）、“消灭城外的劫掠者！”（15–25 级）、“消灭劫掠者首领！”（26–35 级），以及少量新手介绍和旧转职标题“获得英雄资格！”“暗黑之石的秘密”“实力的证明”。实际可用职业、等级与完成状态仍由服务端决定。低级任务已对照 OpenMU v0.10.1 的任务组 18、NPC 257 定义核对；本轮未读取或修改运行中服务器数据库。角色暂不具备资格的分支不算实机通过。

完整中英对照与真实文件关联见源码 `round5-bmd.tsv`、`round5-quest-links.tsv`。Olga、Erin Gustiv、Polluted Butterfly 等未确认专名保留英文。召唤术师 26–35 级分支的客户端正文 18029 写 Hideous Rabbits，摘要 18812 和官方服务器目标却指向 Polluted Butterfly（怪物 419）；这两个原文保留英文，待后续单独核对，未猜改怪物或任务条件。

剩余多数 QuestWords、旧转职标题 5/6、其他任务窗口和服务端聊天仍可能显示英文。本次没有批量翻译全部任务，也未把原文提供的坐标、等级或击杀数量改成其他值。

复制自己的第四轮完整客户端到新目录，退出新副本，将 ZIP 解压到根目录，使 Main.exe、Data 和 shaders 同层。保留原 config.ini 与 Noto Sans SC 字体。

请在第五轮用同一角色与幻影导师交互，检查任务标题、正文、回答、翻页和 zh-CN→en→zh-CN 切换；核对任务选择和奖励状态未变化。经典/现代主题、常用缩放下检查方框、截断和重叠。另检查登录、移动、战斗、拾取、NPC 商店、Helper 保存和运行。只记录实际测过的项目，角色无资格或服务端未提供的任务记未测。

回退时退出第五轮，运行保留的第四轮或第三轮副本，无需改服务器或数据库。构建信息和自动测试记录随包提供；它们不代表游戏内人工验收通过。
