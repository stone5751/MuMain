# 第五轮任务中文与 NPC 气泡测试版

本包仅安装到独立第五轮客户端副本，保留第三轮稳定版和第四轮测试版。沿用自己的合法游戏素材、英文 BMD、字体和 config.ini，不更改 NAS 服务端。

## 已确认任务

幻影导师的 15–25 级任务窗口显示“任务”“消灭城外的劫掠者！”及完整中文正文，分别对应既有 Game Quest 资源、QuestWords 18902、18011。旧版和现代主题均绑定当前语言，切换 en 后恢复英文。

NPC 正文使用独立的 quest-dialogue 覆盖类别，仍按原始 QuestWords ID 和英文原文匹配。正文最多 200 个 UTF-16 单位，仅用于原有 35 行分页正文入口；任务列表标题、回答和其他通用文本仍限制为 50。不会把长正文送入标题的小缓冲区。原始 BMD、任务条件、进度、奖励和回答 ID 不变。

覆盖文件只有第五轮及更新的对应客户端支持；不要把本轮 JSON 单独覆盖回第三、第四轮。未翻译项和其他语言回退英文，坏文件会停用整份覆盖并记录日志。

## 安装、测试与回退

复制自己的第四轮完整客户端到新目录，退出新副本，将 ZIP 解压到根目录，使 Main.exe、Data 和 shaders 同层。保留原 config.ini 与 Noto Sans SC 字体。

请在第五轮用同一角色与幻影导师交互，检查任务标题、正文、回答、翻页和 zh-CN→en→zh-CN 切换；核对任务选择和奖励状态未变化。经典/现代主题、常用缩放下检查方框、截断和重叠。另检查登录、移动、战斗、拾取、NPC 商店、Helper 保存和运行。只记录实际测过的项目，角色无资格或服务端未提供的任务记未测。

回退时退出第五轮，运行保留的第四轮或第三轮副本，无需改服务器或数据库。构建信息和自动测试记录随包提供；它们不代表游戏内人工验收通过。
