# 第四轮 BMD 简体中文覆盖测试版

仅供独立副本测试，不替换第三轮稳定版。基于 v1.37.0；正式游戏素材、原始英文 BMD、字体及 config.ini 沿用你自己的合法客户端。

## 安装与回退

1. 完整复制第三轮反馈版客户端到新目录，例如 `client-zh-CN-round4-bmd-test`，不要创建硬链接。
2. 关闭新副本的 Main.exe，把本 ZIP 内容解压到新副本根目录，覆盖同名文件。Main.exe 与 Data、shaders 应处于同一层。
3. 保留新副本的 config.ini；本 ZIP 不携带配置，服务器地址和端口不会被替换。设置 UI Locale 为 zh-CN，字体选择 Noto Sans SC。
4. 从新副本目录启动 Main.exe。完整构建身份、自动测试记录分别见 localization-build.txt 和 ctest-results.xml；files.sha256 提供逐文件校验。
5. 回退时退出测试版，重新启动保留的第三轮反馈客户端。无需改 NAS 或数据库；不要把测试版的配置复制回稳定版。

## 本轮范围

- 中文覆盖文件为 `Data/Local/BmdText.zh-CN.json`，共 68 条：顶部提示 20、技能 28、旧转职标题 2、QuestWords 18。每条附种类、ID、英文原文和中文，便于复核。
- 原始英文 BMD 和技能/任务数据表保持不变。只有 UI 语言 zh-CN 启用覆盖；英文或其他语言、缺少条目、ID 对应原文不符均保留原文。
- 文件缺失、格式错误、重复/非法 ID、超长文本或格式符不一致时，整份覆盖停用并写入 MuError.log，游戏继续用原始文字。修改覆盖文件后需要重启客户端。
- 顶部提示没有独立文本 ID，使用 `等级块索引 × 32 + 槽位` 并核对原文。版本文件身份由安装前的只读校验器核对；运行时逐 ID 核对原文，未知版本不会按英文单词全局替换。
- 语言切换会重建当前任务的显示文字和分页，顶部当前提示重新从右侧滚动；不会重新接受/完成任务，也不会重发 NPC 请求。技能提示再次显示时采用当前语言。
- 另补充 15 条已有 Game 界面资源，详见源码 `docs/localization-audit/round4-game.tsv`。

## 人工验收清单（构建时均未测试）

请从此副本进入测试角色，记录实际执行结果；不要为验收修改角色或数据库。

1. 冷启动、收到服务器列表、登录角色；移动、战斗、拾取、背包及 NPC 商店正常。
2. 开启顶部操作提示，低等级角色等待轮播：ID 12「按空格键拾取物品。」、ID 24「按 D 键打开指令菜单，可使用交易、组队、密语等功能。」、ID 28「按 T 键查看任务信息。」。轮播受原来的角色等级限制；没有抽到某条不能判失败。
3. 有对应技能的角色检查技能栏、物品技能说明和 Helper 技能选择的悬停提示：火球术（4）、黑龙波（9）、霹雳回旋斩（41）、治疗（26）。无需购买技能或改角色数据；不可触发的样本标未测。
4. 有首次转职任务资格的角色，在任务窗口/NPC 面板检查「寻找帝王之书」（Quest 0）和「奇迹大陆的三种宝物」（Quest 1）。旧转职正文来自既有 Dialog 资源，仍沿用第三轮译文。
5. 可进行新手教学的角色与幻影导师交谈，检查 QuestWords 2「继续听下去。」、15「很高兴认识你。;请问你是谁？」、26 的 C 键角色属性教学。分号是原有段落分隔符。服务器可能不支持该教学，无法触发时记未测。
6. 依次切换 zh-CN → en → zh-CN，检查技能提示、正在滚动的顶部提示、打开的任务标题/正文/回答、任务摘要及分页。当前选中任务、奖励/完成按钮状态应保持，页面超出新页数时会收敛到末页。

8. 经典和现代主题，在常用分辨率及 75%/150% UI 缩放下检查方框、截断、重叠；字体 cmap 自动检查不等于实际显示通过。
9. 退出测试版，把覆盖 JSON 临时改名，再启动：应保留英文 BMD 文字并正常进入登录场景；恢复文件名后重启恢复中文。仅操作测试副本。

## 尚未覆盖和限制

多数技能、任务正文、旧任务标题及其他等级块的顶部提示仍用原文。名称不确定的未纳入样本。QuestWords 中文上限暂设为 50 个 UTF-16 单位，以兼顾同一文本表还用作任务列表标题的 64 字符缓冲区，并预留编号空间；首批最长 49 个单位。长正文先保留英文，后续须按用途验证容量再扩展。

系统聊天 `Inventory is full` 和 `Talking to this NPC (...) is not implemented yet.` 来自 OpenMU；本包不替换服务端消息，也不改变服务器语言。服务器不支持的 NPC 对话不会因客户端翻译而实现。

所有自动化结果以此次实际 Actions 记录为准；本 README 随构建产生时不代表游戏内人工验收通过。未经实机验证，不晋升为稳定版。
